# 实验协议

## 三类证据

- **数值验证**：质量总量、拉普拉斯投影和二次能量恒等式、阻尼半正定、轴向弹簧静止态/内力平衡、有限差分梯度、线性积分逐步与矩阵幂一致、STE梯度、聚合非空与控制点保留。
- **合成诊断**：cloth/rope，36节点、32帧、3条不同控制轨迹；3方法×3种子×2对象=18次。训练只看前16个未来帧，后16帧评估；每个训练80轮，隐藏128维，16子步。
- **真实数据子集**：PhysTwin `double_lift_cloth_1`，116帧，官方train=[0,81)、test=[81,116)；64物体点+4控制点，3方法×3种子=9次。各层全序列递推，无测试期状态重置，无未来轨迹监督。测试期控制输入可用，符合受控前向预测。

**不能把同一条序列上的未来预测当成跨物体泛化。** 合成和真实子集的模型及指标分别报告。

## 资源使用

M4 Pro，12核CPU（8性能+4能效）、16核GPU、48GB统一内存。CPU对照使用6个独立工作进程，每进程1个PyTorch/BLAS线程，避免嵌套线程争用。大批量计算另外运行Apple MPS。没有使用远程GPU。

硬件微基准由 `scripts/check_mps.py` 生成，包含前向与反向，在同输入下检查CPU/MPS位置和梯度。微基准的单次时间含初始化开销，不作为稳定吞吐结论。训练日志记录每轮耗时；推理计时运行3次，MPS前后同步，计时包含状态投影和恢复、不含模型重建与渲染。这里的FPS不是论文端到端FPS。

## 已修正问题

- CPU float64的固定点掩码投影dtype不匹配：修正后结构测试通过。
- 硬件测试拷贝后的非叶张量不保留grad：改成独立叶张量后复测。
- 第一轮真实数据诊断把零有效点帧的距离占位值计入Chamfer：增加有效帧掩码及回归测试；`real_pilot`保留为历史结果，**不用于最终结论**。
- `pilot_mps`误用了CPU默认选项，名称有误；真正GPU试验是`pilot_mps_actual`，以配置中的device为准。
- `suite`是早期探索；最终使用`suite_final`。历史目录保留，不混入正式汇总。

## 后续异常审计

真实布料seed0在16子步训练的第70轮出现范数溢出：各梯度元素有限，双精度范数1.191e27，单精度范数为无穷。相同权重、同一Gumbel随机状态改32/64子步，范数分别降至2.615e13/3.061e5。已确认单精度范数溢出；也确认梯度对步长敏感，尚未证明更细步数的训练梯度收敛。

`safe_clip_grad_norm`保留正常数值下原PyTorch裁剪路径，只有溢出时使用双精度；非有限梯度元素仍报错。恢复16子步seed0后得到80轮结果，其L3表现较差，完整保留入均值。最后10轮改64子步的结果单列为敏感性，不替换较差结果。

主表真实追踪来自处理后的观测轨迹，并非官方全部评估。额外读取`gt_track_3d.pkl`的9条标注轨迹，以初帧3近邻逆距离加权位移插值进行独立检查；未来坐标仅用于评分，不用于预测或训练。结果见`sparse_gt.json`。

## 最终判断与下一步

代码实现：可执行的主体参考实现，存在明确偏离。实验运行：完成27次正式对照、GPU训练和额外64子步敏感性，共29份完成记录。趋势：降阶加速存在；学习式聚合质量优势未得到支持。论文数值：未匹配，未覆盖完整基准。

下一轮优先查验Eq.6的列数/代表选择/空簇规则、非线性弹簧的缩减一致性、官方阻尼与自碰撞，再补Gramian/两阶段PhysTwin及完整场景。当前结果不能用于否定作者方法，因为实现假设与原实验尚未对齐。
