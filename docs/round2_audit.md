# 第二轮：节点合并与物理模型核查

本轮保留首轮代码与实验；新入口为 `physpring.experiment_v2`，旧入口不改变。源代码、固定拓扑、逐轮损失、随机状态及失败现场在每个运行目录保存。结论分为原文确认、独立实现假设和实验观测。

## 1. 节点合并：可确认与未披露之处

论文式 (6) 以潜在距离定义分配，但给出的 N×N 形式和逐行归一化不足以唯一确定 N→n 的非空簇数。若所有节点都可作为代表且保留自分配，互异特征的无噪声最近邻是自身，不能减少节点。`scripts/audit_reduction.py` 的随机特征示例验证了这一点；该示例不是学习后特征的统计，也不能证明所有 Gumbel 样本都不合并。

独立实现继续明确采用：给定缩减比例 0.6/0.4/0.3（相对原节点数）、FPS 代表节点、控制节点单独成簇、代表节点占有自身以保证非空列、质量加权静止位置与状态投影。这些规则并非作者已确认的实现。

- **修正冻结规则**：Gumbel 分数除以温度不会改变硬 argmax；仅降温并不能减少硬分配随机性。新流程只扰动当前训练的合并层，每阶段最后 25% 迭代关闭噪声，冻结最后一次实际受监督的分配。旧流程在冻结时重新计算无噪声拓扑，可能引入未训练的图。
- **局部合并消融**：`--merge local` 限制到几何上最近的 3 个非控制代表，代表自身仍固定。这是空间约束假设，不是从论文恢复的隐藏规则，也不保证簇在原图中连通。
- **随机基线修正**：随机抽代表、随后按几何最近邻分配。首轮是随机分区，不能称作标准随机采样基线。新旧随机结果不可当作只改变物理模型的对照。
- **参数头**：论文式 (9) 是加性修正，新头对刚度采用 `k_base + beta * head`，对称化并截断为非负；beta 取每层基准边刚度均值。该 beta、非负投影、阻尼头的共享平均及接触参数的指数修正仍是独立实现假设。

## 2. 物理差异

对照来源：论文原文及 PhysTwin 公开 `spring_mass_warp.py`、`real_data.py`；下载副本与来源清单位于 `sources/`。

| 项目 | 首轮 | 第二轮 reference 模式 | 证据/限制 |
|---|---|---|---|
| 弹簧伸长 | Hooke k(l−l0) | 保留 Hooke k(l−l0) | 原基准 Y(l/l0−1)，Y=k*l0 时完全等价；不能把单位转换误认为缺少物理项 |
| 边阻尼 | 完整矩阵 −Dv | 相对速度在弹簧轴上的投影 | 横向相对运动不直接产生该边阻尼力；已验证内力抵消 |
| 空气阻尼 | 显式力 | 每子步速度乘 exp(−h*rate) | 从投影 D 的行和恢复质量归一化 drag rate |
| 地面接触 | 罚力刚度/阻尼 | 恢复系数、库仑切向冲量、碰撞时刻积分 | 初始 e=.5、mu=.3；已在穿透状态上额外截断 TOI 到 [0,h] |
| 控制位置 | 先受力后设置 | 每子步先设置下一个插值位置再受力 | 控制速度默认 0，符合检查到的公开状态初始化；可选 finite_difference，不代表作者全部管线已确认 |
| 重力 | 9.81 | 9.8 | 坐标统一转为 z 向上 |
| 几何损失 | 对称平方 Chamfer | 观测→预测单向最近邻平方距离 | 可见性掩码独立使用 |
| 追踪损失 | 均方误差 | SmoothL1(beta=1)，坐标均值 | 使用运动有效性掩码，不再与可见性静默求交集 |

`System.contact` 在旧模式中为罚力参数，在新模式中为 `[restitution, friction, unused]`。入口负责转换；不能跨模式直接复用接触参数。正式消融的评估指标仍统一采用首轮交集掩码的欧氏追踪与对称 CD，方便受控比较；训练目标的变化与评估口径分别记录。

可选自碰撞实现为对称双粒子冲量，排除弹簧邻接；已测试双粒子动量守恒。但它不等同于 PhysTwin 按接触邻居数平均、多物体簇掩码的完整接触实现。默认关闭，不把它计为原始自碰撞复现成功；多接触能量、接触图与穿透消除仍需补足。

## 3. 标量投影不等于非线性轴向动力学一致

标量拉普拉斯投影 `L_c=Pᵀ L_f P` 在当前实现可精确满足。但轴向弹簧在静止位置的三维切线矩阵由每条边的 `k*n*nᵀ` 组成。把多个细边折成两簇质心之间的一条轴向弹簧，一般不能保存这些方向张量。

诊断分别计算：

1. 细网格切线刚度 H_f；
2. 精确投影 `(P⊗I)ᵀ H_f (P⊗I)`；
3. 质心弹簧图的 H_c；
4. 保留静止偏移的细网格力提升/投影 `Pᵀ F_f(x_rest + P*u_c, P*v_c)` 的自动微分雅可比。

初始 68→41 节点图上，三种分配的标量投影误差均为 0，但相对三维切线误差为约 20.9%–40.6%。保留细边的投影力雅可比与精确投影的最大差约 6e−14，支持差异来源判断。此诊断仅针对本实现初始图，不是作者模型的实测错误，也不是预测误差的单一因果证明。

`reduction_audit.lifted_force` 提供精确受限运动诊断，但仍计算细边，不具有粗图加速。未将其混入正式速度比较。未来若使用张量刚度、边束或残余内变量，应另设方法分支，不能作为论文原方法静默替换。

## 4. 受控实验与本地计算

`configs/round2_plan.json` 固定 8 个方案 × 3 个种子。所有方案使用同一真实布料序列、64 个物体点 + 4 个控制点、训练 80 帧与未来 35 帧、80 轮、16 子步、hidden=128。六个 CPU 任务并发，每任务一个计算线程。Apple GPU 另做物理/梯度对齐和 144 节点、16 条轨迹的 80 轮合成诊断；其目标由新物理生成，不能与首轮合成误差直接比较。

- legacy：旧模型、旧物理、旧损失、旧冻结；对照复跑。
- loss_only / physics_only / schedule_only：分别改变损失、物理、冻结流程。schedule_only 同时使用精确 hard-forward STE，避免旧表达式浮点抵消误差。
- full_global / full_local：全部修正，分别全局或局部代表分配。
- full_geometry / full_random：相同新物理与目标的几何/随机代表对照。

失败原样保留并报告完成数；失败方案不报告误导性的三种子均值。前向子步敏感性不是反向梯度收敛证明。完整论文的 667 子步训练、全部数据点、两阶段基线、Gramian、渲染与机器人实验仍未复现。

已有完成结果可缓存复用。失败目录应保留；同配置重试使用新输出目录。`experiment_v2` 不支持恢复训练，拒绝非空输出目录；首轮恢复入口仍保留。训练源文件副本在每次运行的 `source/`，运行中不要修改计算代码。

### 已定位的数值失败

`physics_only_2` 在第 67 轮、更新前损失非有限。保存的同一随机状态与参数重放显示，L0 在 16 子步时非有限，32/64/667 子步均有限，其余层在这些设置下均有限。这支持时间离散稳定性问题；仅检查弹性线性化的 h*omega<2 不足以保证包含显式阻尼、接触及非线性的全过程稳定。`failure_replay.json` 保留所有层的诊断。另设 `physics_only_2_steps32` 从头重训，不替代正式失败种子，也不混入 16 子步的统计。

### 短训练与源码追踪修订

在正式 80 轮任务期间，额外测试发现 8 轮试跑的阶段长度只有 2，旧分数阈值不会留下确定性尾段。入口已改成按整数阶段边界至少保留一轮确定性训练；测试证明 80 轮的每个采样开关与原本完全相同。`pilot` 排除正式汇总。恢复训练的不可达旧代码已移除。运行中各进程已经加载其训练入口；源码副本是该运行的权威证据。较早任务的结束时哈希可能反映随后的小修订，复核应使用 `source/`；后续入口改为直接对启动副本哈希。

### 运动掩码索引复核与结果替换原则

进一步逐行核对 `spring_mass_warp.py` 的初始化与帧更新：目标帧 t 使用 `object_visibilities[t]`，但使用 `object_motions_valid[t-1]`，因为后者表示前一帧到当前帧的运动有效性。初次第二轮数据准备错用了后者的 t 索引；训练区间有 342 个点帧标记不同，未来区间有 164 个。修正数据保存在 `double_lift_cloth_1_64_round2_aligned.pt`，未覆盖旧文件。

所有使用 reference 损失的 15 次训练（loss_only 与四种 full 方案，各三种子）在 `results/round2_aligned/` 从头重跑。正式表读取这些重跑结果，以及 `round2/` 中不使用 reference 损失的九次对照。初次 reference 损失训练只作为索引修正前的历史证据。GPU 合成诊断没有这些真实数据掩码，不受影响。`masks.align_motion_mask` 有专门的时序单元测试。

最终训练只采用论文所述几何与追踪项，并未复刻 PhysTwin 完整优化器：公开基准还包含 `acc_weight=.01` 的速度增量平滑项与其状态更新。质量、初始参数也保留受控子集设置（物体总质量假设 1 kg、k=18 N/m、边阻尼 .03、drag rate .1），而非直接复制基准配置的 Y=3e4、dashpot=100、drag=3。参数单位映射、点数、质量与图同时相关，不能只替换某个数字就称作原始物理配置。另有初始图使用对称 6-NN，而基准使用距离半径及邻居上限。这些是仍存在的实质差异。

重建最终训练应在准备数据后运行 `python scripts/run_round2.py --aligned --workers 6`；不加 `--aligned` 保留初次受控审计入口。报告自动选择上述最终来源。

`results/round2/full_global_0/substep_sensitivity.json` 是时序校正前检查点的前向诊断：L3 从 16 子步的 30.315 mm 到 667 子步的 30.418 mm。这不能替代校正后结果，也不能推广到发散检查点。修正掩码前后全部同种子的差值由 `scripts/audit_mask_effect.py` 保存，不只展示有利变动。

### 冻结差异的直接证据

对旧版三个种子的最后受监督分配与实际评估分配逐节点比较，L3 分别有 22、15、22 个节点换簇（68 个原节点）。这不是 STE 舍入误差：最大分配差为 1。确定性尾段的新流程在相同检查中为 0 个换簇且矩阵精确相同。逐运行证据见 `results/round2/topology_freeze_audit.json`。各运行额外的 `source_snapshot_hashes.json` 直接校验启动时源码副本，不覆盖历史结束时哈希。

## 最终结果与证据边界

正式八方案 × 三种子的 24 次对照中，23 次完成，physics_only seed2 在 16 子步失败。另有 15 次监督索引修正前的完整历史运行、GPU 合成运行及 32 子步重训，共 40 份完整结果通过日志与检查点核验；试跑 pilot 不计。19 项测试通过。CPU 检查点重建误差全部为 0；GPU 长序列转 CPU 重建最大差 2.01e−5 m，短物理对齐最大差 2.98e−7 m。

L3 未来观测误差（mm，样本标准差）：旧版 40.276±11.884；新全局 33.413±2.308；新局部 30.194±0.868；新几何 27.969±0.224；新随机代表 27.906±0.923。仅冻结修正为 33.865±5.228，仅损失修正为 34.010±4.071。不同因素并不保证独立可加；三个种子的均值变化不等于统计显著性。

新局部相对旧版均值降低约 25%，但学习式仍不优于同设置几何/随机代表。细层 L0 也从旧版 20.837 mm 上升至新局部 27.225 mm，说明并非所有层均改善。新物理的未训练初始细网格为 28.520 mm；与训练后约 27 mm 的差距不大。9 条独立标注轨迹上，L3 旧版 34.031±14.290 mm，新全局 28.896±1.474，新局部 26.332±0.906，新几何 23.275±0.527，新随机 26.313±2.228；该独立插值口径同样不能验证论文优势。

新全局的 L3 三个种子分别有 4/7/7 个不连通簇，新局部为 1/0/0（总簇数 20），支持空间约束减少不合理聚合，但不证明连通性得到硬性保证。所有确定性尾段运行保存前后分配相同。

校正后全局 seed0 的 16→667 子步前向检查：L0 27.207→27.319 mm，L3 32.310→32.223 mm。32 子步敏感性重训完成 80 轮，L0=27.180、L3=28.792 mm；不替换失败种子，不证明 667 子步反向梯度已收敛。

最终结论是实现错误与假设边界更清楚、局部实验更稳定，尚未得到作者方法的质量优势或完整论文数值匹配。
