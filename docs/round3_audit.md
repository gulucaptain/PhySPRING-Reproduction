# 第三轮：三维轴向受力、合并子空间与梯度路径

## 证据来源与范围

核对 [PhySPRING v1](https://arxiv.org/html/2605.07687v1) 的式 (1)、(6)–(9)、附录 A 和 Algorithm 1，以及本地保存的 PhysTwin `spring_mass_warp.py`。论文网页可读取；项目主页本次工具访问失败，未据此断言代码发布状态。所有旧实验保留，新文件使用 v3 命名。

论文式 (1) 写成标量图拉普拉斯作用于 N×3 坐标；式 (8) 投影 N×N 的 M/L/D；但公开 PhysTwin 的实际弹簧力是沿当前边方向的非线性应变力。论文没有给出合并后的静止长度、细边方向分布、张量块刚度如何进入 Warp 的完整对应关系。因此不能把字面 `L*X`、位移线性模型和非线性轴向弹簧当作完全相同的物理模型。

本轮保留 PhysTwin 风格轴向弹簧作为主要模型；新增精确受限运动的受力实现用于诊断。它保留原始细边，不是论文声称的单一粗边模型，也不能用其速度声称复现了论文加速。

## 1. 三维轴向缩减的具体差异

设原节点 i 属于簇 a，约束细网格运动为 `x_i=r_i+u_a`。细边 e=(i,j) 的当前向量是

`d_e = (r_i-r_j) + u_a-u_b`。

精确受限模型在这条向量上计算轴向弹力与轴向阻尼，再求 `Pᵀ F_f`。质心单边模型则先求簇质心，把所有细边替换为质心向量 `r̄_a-r̄_b` 和一个系数。两者一般不相等，即使 `L_c=Pᵀ L_f P` 精确成立。

静止处，每条细边贡献 `k_e*n_e*n_eᵀ`。两簇之间的真实方向块为这些 3×3 矩阵的和；通常秩大于 1。质心单边只能表示 `s_ab*n̄_ab*n̄_abᵀ`，最多秩 1。所以仅修正一个标量刚度，无法一般性恢复缺失的方向响应。

`make_bundle_force` 用原始无向边的关联矩阵乘 P 计算上述力，不在反向传播中删除簇内边。单元测试验证：与密集细边受力再投影一致、对位置的梯度一致、内部合力为零、静止切线等于 `(P⊗I)ᵀ H_f (P⊗I)`。其接触和空气阻尼仍采用粗模型；“精确”只指给定簇平移约束下的内部弹簧/轴向阻尼力。

三个固定分组的反事实模式：

- centroid：普通质心弹簧，系数按标量 Galerkin 投影。
- bundle：保持同一个细网格、同一个 P、同一质量与粗接触设置，保留每条细边的静止向量与方向。
- tangent_matched：每个粗边独立选 `n̄ᵀ K_ab n̄`，在固定质心方向下最小化对应非对角方向块的 Frobenius 误差。它不保证整个 H 的全局最优，也不保证大变形轨迹最优，不是论文原方法。

对照不拟合观测、不按未来帧选参数，统一使用初始细网格参数，因此隔离的是分组与受力压缩，不是训练后不同解码头的差异。轨迹参考使用同一初始细网格在 32 子步下的模拟。另单独记录真实观测误差。

## 2. 分组表示能力与动力学近似必须分开

簇平移模型会删除簇内相对运动。即使精确计算投影内力，也不能恢复这些自由度。为量化这一点，诊断允许用各帧真实位移对每个簇求最小二乘位移，再恢复到细网格，记录有效观测上的 RMS 误差。

这是使用未来数据的**事后表示能力诊断**，不是可部署预测，不能与正式平均欧氏追踪误差混用，也不能把它当作新的训练成绩。没有任何未来观测参与正式训练、选簇或参数选择。

## 3. 质量矩阵反向传播的确认问题

旧实现计算 `M_c=Pᵀ M P`，随即仅保留 `diag(M_c)`，并使用它归一化 `Pᵀ M x`。当 P 是硬 one-hot 时，该前向质量和状态完全合理；但 STE 的反向传播允许 P 连续变化，这时 M_c 不再是对角矩阵。只保留对角的导数、却丢弃非对角导数，会破坏常量位移的平移一致性。

新 `project_full/pool_full` 使用完整的 `M_c`，解 `M_c*x_c=Pᵀ M*x`，并在受力积分时保留完整逆质量矩阵的梯度；多层投影也保留完整质量矩阵。硬分配前向仍为相同的对角质量模型（浮点运算顺序可有差异）。

测试包括常量状态的行单纯形切向梯度、软 P 的有限差分、硬 P 的旧新前向一致性、整体坐标原点平移后物理损失梯度一致性。此修正使一种连续松弛自洽，不意味着 STE 成为离散合并的真实梯度，也不能在未看到作者实现时声称作者采用同一反向方式。

## 4. 与论文训练设置的差异

- 论文式 (2) 写多层目标，Algorithm 1 写当前层 `l*` 的监督，附录文字还强调已提交拓扑层的监督；`E_commit`、`K_model`、`K_col` 的可复跑取值未给全，伪代码初始索引也不能直接确定本实现的四阶段边界。
- 原独立实现累计监督 `0..stage`。本轮额外测试只监督当前层 `stage` 的 active 方案，其他设置相同。这是对监督范围的受控消融，并非完整还原 Algorithm 1；冻结时机、内循环次数、单独接触更新仍有差异。
- 论文称编码器有五个下采样层，仅四层进入模拟；当前模型只有四个编码/解码层。未把新增一层作为已确认修复，因为层次映射和缩减率仍未披露充分。
- 原始节点数、图构建、质量/初值、两阶段基线、渲染与机器人任务仍未匹配。本轮训练仍是单个布料 64 物体点 + 4 控制点、三种子、80 次 Adam 更新、16 子步。667 子步只做短序列轨迹和梯度核验，不是完整长时域训练已收敛。

## 5. 预定实验与复跑

18 次 CPU 正式训练：full_global / full_local / full_geometry / full_random / active_global / active_local，各种子 0/1/2。前四者只改完整质量矩阵松弛；后两者再改监督范围。六个进程并发，每进程单线程。旧结果引用 `round2_aligned`，不覆盖。

Apple GPU 另运行 144 节点、16 轨迹、80 轮的完整质量松弛训练，以及 16/667 子步的两帧 CPU/GPU 对齐。合成结果不与真实子集混合。

```sh
python -m pytest -q

python scripts/audit_axial_reduction.py

```

### 初步确认的边界

完整质量松弛修正并未消除所有 STE 近似：硬图的边索引仍取自停止梯度的非零模式，代表节点仍由 FPS 指定，局部候选仍为最近三个代表；空气阻尼/接触仍沿用已披露的独立实现选择。不能把该修正称作整个离散拓扑优化的精确梯度。

667 子步两帧诊断中，真实子集 centroid 模式的刚度比例梯度从 16 子步的约 9.36e−8 变为 667 子步的 2.44e−7；bundle 模式从约 2.84e−7 变为 4.45e−7。这些梯度绝对值很小，具体量级依赖诊断目标，但足以说明“位置接近”不是梯度收敛证明。CPU/GPU 在相同子步下最大位置差 1.25e−6 m，比例梯度最大绝对差 6.22e−10；GPU 数值一致性与时间步收敛是两件事。

## 6. 完整训练与反证结果

本轮 18 次真实子集训练及 1 次 GPU 合成训练全部完成（pilot 不计）。26 项测试通过。正式 L3 未来观测误差：

| 方案 | 均值 ± 样本标准差（mm） |
|---|---:|
| 完整质量松弛，全局学习式 | 34.239 ± 1.569 |
| 完整质量松弛，局部学习式 | 27.083 ± 0.792 |
| 完整质量松弛，几何代表 | 28.214 ± 0.115 |
| 完整质量松弛，随机代表 | 27.630 ± 0.203 |
| 再改仅当前层监督，全局 | 33.798 ± 4.785 |
| 再改仅当前层监督，局部 | 28.249 ± 2.028 |

局部学习式相比第二轮 30.194 mm 降低约 10.3%，三个种子均降低；全局学习式相比 33.413 mm 反而略升。新局部仅在当前主指标的均值上略低于几何/随机，不能据此宣称论文优势已复现。

**独立标注不支持同样的排名**：9 条标注轨迹的初帧 3-NN 插值评估中，新局部为 24.198±2.685 mm，几何为 23.412±0.275 mm，随机为 25.603±1.503 mm。局部仍未超过几何。此评估也不是官方完整评估器。

**固定分组对照仍有数值漂移**：几何/随机的硬分组完全相同，却因求逆/矩阵乘法与除法的浮点计算路径不同，训练后的主指标均值从第二轮 27.969/27.906 mm 变为 28.214/27.630 mm。两条前向路径在数学上相同，不保证训练轨迹逐位相同。不能把约 0.55 mm 的新局部对随机优势全部归因于质量梯度修正，更不能当作显著性结论。

**分组表示能力没有随主指标同步改善**：新局部的事后位移表示 RMS 为 24.548 mm，旧局部为 23.367 mm；新全局为 38.440 mm，旧全局为 34.483 mm。几何/随机仍为 21.073/21.674 mm。因此“局部训练误差降低”不能解释成“新簇必然更符合真实运动”；机械参数与拓扑的联合作用仍需要区分。

**监督冲突假设未得到支持**：在第 79 轮更新前的六个全局/局部检查点，对共享编码器分别计算 L0 与 L3 梯度，余弦均为正（约 0.020–0.390）。仅当前层监督也没有稳定改善。这只是末轮快照，不排除其他轮次出现冲突，但不支持把普遍梯度对抗当作现有差距的主要原因。

GPU 合成训练 144 节点、16 轨迹、80 轮约 77 秒，记录驱动内存峰值约 4 GB；L3 未来误差约 150.5 mm，未优于第二轮的 132.9 mm。GPU 跑通与物理梯度修正不代表所有任务精度都改善。

## 7. 固定权重/分组互换：改善来自哪里

对六个全局/局部种子进行旧/新权重 × 旧/新冻结分组的 2×2 交叉评估，全部用同一 v3 前向，不重训、不用未来目标选参数。由于改变分组也会改变编码器/解码器输入，不能把权重与分组视为完全独立因素，但可以检验条件效应。

| 局部方案 | 旧分组 | 新分组 |
|---|---:|---:|
| 旧网络权重 | 30.194 mm | 29.124 mm |
| 新网络权重 | 27.981 mm | 27.083 mm |

保留旧分组而换新权重，均值降低约 2.21 mm；保留旧权重而换新分组，降低约 1.07 mm。这个对照支持改善与参数学习和分组的共同变化有关，不能仅归因于几何表示能力提升。旧权重/旧分组在统一前向中重现第二轮成绩，误差约几微米以下。

全局方案四格为旧/旧 33.413、旧权重/新分组 34.151、新权重/旧分组 35.044、新/新 34.239 mm，并没有同样的改善。原始记录在 `map_parameter_swap.json`。几何/随机的六组冻结分配矩阵逐元素与第二轮相同，记录在 `fixed_map_comparison.json`。

## 8. 结论与下一步边界

- **已确认并修正**：旧状态池化/质量反向传播在连续松弛下失去平移一致性；新方式保留完整质量矩阵的相关导数，通过软分配有限差分和原点平移检验。
- **已测得，但不是单独充分原因**：三维方向压缩误差与簇内运动损失。精确投影内部受力没有普遍改善动态轨迹，不能把 bundle 直接升级为默认复现方法。
- **本子集上的改善**：局部学习式主指标从 30.19 降到 27.08 mm；权重/分组互换支持二者共同作用。小幅领先新主指标基线，但独立标注仍不如几何，不能声称复现论文优势。
- **没有支持的解释**：仅靠改为当前层监督，或把普遍的细粗层梯度冲突当作主要原因。末轮正余弦与监督消融只在当前检查范围内反驳这一解释。
- **仍待解决**：667 子步长时域反向收敛、真实质量/材料初值与图密度、作者未披露的合并规则、五层编码器配置、内循环/接触更新与完整场景评估。

新增代码与实验入口：`physics_v3.py`、`model_v3.py`、`experiment_v3.py`、`evaluate_v3.py`；完整结果和图见 `results/round3/results.md`、`comparison.png`。`scripts/report_round3.py` 重建表图，`scripts/verify_round3.py` 核验日志、检查点轨迹和最终冻结图；`scripts/evaluate_sparse_gt_v3.py` 重建独立标注结果。所有 CPU 完整运行的检查点轨迹重建误差为 0，GPU 检查点转 CPU 最大差约 1.37e−6 m。
